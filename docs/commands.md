# 命令手册

> 命令前缀默认为 **`%`**（由 `.config/main/.env` 的 `COMMAND_START` 决定）。
> 标【所有者】的命令仅 `SUPERUSERS` 可用。

## 1. 总控插件（`paperbot_console`）

| 命令 | 别名 | 说明 | 默认权限 |
|---|---|---|---|
| `%help [插件名]` | 帮助 / 菜单 / 列表 / list | 无参：列出**当前已启用**的插件；带参：看该插件的命令与介绍 | 所有用户 |
| `%on <插件名> [目标]` | 开 / 启用 | 在对应作用域**启用**插件 | 【所有者】 |
| `%off <插件名> [目标]` | 关 / 禁用 | 在对应作用域**禁用**插件 | 【所有者】 |
| `%plugin <插件名>` | 插件 / 状态 / status | 查看该插件在**全局 / 各群 / 各成员**的开关状态 | 【所有者】 |
| `%admin add <QQ> [群号]` | 管理员 / 权限 | 授予 **2 级管理员**（仅对应群） | 【所有者】 |
| `%admin del <QQ> [群号]` | | 移除手动授予的管理员 | 【所有者】 |
| `%admin black <QQ>` | | 加入**全局黑名单**（0 级） | 【所有者】 |
| `%admin unblack <QQ>` | | 移出全局黑名单 | 【所有者】 |
| `%reset <插件名> [作用域]` | 重置 | 清除某作用域的规则 | 【所有者】 |

**作用域写法**（`%on` / `%off` / `%reset` 统一）：

| 写法 | 含义 |
|---|---|
| 省略 | 当前群 |
| `全局` / `all` | 全局生效 |
| `本群` | 当前群（显式写法） |
| `群:<群号>` | 指定群 |
| `用户:<QQ>` | 指定成员 |

> 受保护插件（总控自己）**永远放行**，不能被 `%off`。

## 2. 人设对话插件（`paperbot_chat`）

| 命令 | 别名 | 说明 | 默认权限 |
|---|---|---|---|
| `%ai <内容>` | `%AI` / `%聊` | 与 AI 人设对话（**个人上下文 + 长期记忆**） | 普通用户 |
| `%ai 群 <内容>` | | 群聊作用域对话（群共享上下文，不注入个人记忆） | 普通用户 |
| `%ai 流式 <内容>` | | 流式生成演示（会报流了几片） | 普通用户 |
| `%ai 印象` | | 看看 AI 眼中的我（印象 + 关键信息） | 普通用户 |
| `%ai 记住 <键> <值>` | | 手工记一条关键信息（**不会被自动提炼覆盖**） | 普通用户 |
| `%ai 忘记 [键]` | | 删掉一条 / 全部关键信息 | 普通用户 |
| `%ai 重置` | | 清空我的对话上下文 | 普通用户 |
| `%ai 人设 [名字]` | | 查看 / 切换我的人设 | 普通用户 |
| `%ai 状态` | | LLM 可用性 / 服务商 / 人设 / 上下文条数 | 普通用户 |
| `%ai 停` | | 手动关闭本群「对话模式」（群聊） | 普通用户 |
| `%ai 群状态` | | 查看本群「对话模式」状态（群聊） | 普通用户 |

**群聊「对话模式」**（`group_mode` 配置项开启时生效）：

1. 群里 **艾特一次** 白纸 → 开启该群的对话模式（默认 `group_timeout=300` 秒没人说话自动关闭）；
2. 之后该群 **免艾特**：普通消息 bot 也会自动接话（`group_cooldown` 秒冷却，防刷屏）；
3. `%ai 停` 手动关闭；`%ai 群状态` 查看剩余状态。

**插件配置项**（WebUI「插件管理」页可改，即时生效）：

| 键 | 说明 |
|---|---|
| `preset` | 默认人设名 |
| `render` | 回复是否渲染成图片 |
| `max_chars` | 超长回复截断长度 |
| `cooldown` | 每人冷却秒数 |
| `group_mode` | 群聊对话模式开关（艾特触发后免艾特自动回复） |
| `group_timeout` | 群对话模式超时秒数（0 = 不超时） |
| `group_cooldown` | 群自动回复冷却秒数 |
| `group_history` | 注入上下文的最新群聊消息条数（0 = 不注入） |

详见 [`llm.md`](llm.md)。

## 3. 示例插件（`paperbot_echo`）

| 命令 | 别名 | 说明 | 默认权限 |
|---|---|---|---|
| `%echo <内容>` | `%复读` | 复读内容（用来验证门控与输出守卫） | 普通用户 |

**插件配置项**：

| 键 | 说明 |
|---|---|
| `empty_reply` | 不带参数时的回复 |
| `upper` | 是否把回复转成大写 |

## 4. 命令权限怎么改

命令的**实际权限等级**由框架维护、可在 WebUI「**命令管理**」页改：

- 插件只声明**默认等级**（`level=1|2|3`）；没有改过的命令**跟随默认值**（数据库里不留记录）
- WebUI 下拉改完**即时生效**（无需重启）；「恢复默认」即删除覆盖记录
- 受保护插件（总控）的命令**锁定不可改**（接口返回 409）
- 插件自己用自定义 `permission=` 托管的命令，框架不插手（WebUI 标为不可编辑）

## 5. 权限等级

| 等级 | 名称 | 说明 |
|:---:|---|---|
| `0` | 黑名单 | 不回应任何消息（一票否决） |
| `1` | 普通用户 | 默认 |
| `2` | 群管理员 | 群主 / 管理员**自动识别**，或所有者手动授权（仅对应群） |
| `3` | 所有者 | `SUPERUSERS` |

解析优先级（就近优先）：**所有者 → 本群手动授权 → 全局手动授权 → 群角色自动 → 默认普通**。
详见 [`architecture.md`](architecture.md#3-四级权限)。
